# DeepBook板分析・判断スコア・戦略比較

基準main: 1f69022。PR-Aのコードは含めない。ネットワーク取得、EMA/RSI/MACDのルール、ProfitGuardとリスク制限、PAPER専用実行を維持する。

## 変更前と原因

板の検証と両側の厚み確認は既存実装済み。Imbalance・数量別価格影響の判断ログはなく、RuleBasedStrategyの非WAIT判断は一律0.7。confidenceはStrategyPanelで百分率表示されるが、リスクエンジン・注文処理は参照していない。固定値では比較・校正に使える情報がない。

## 分析と運用

既存の取得済み板をコピーして利用し、追加API呼出しはしない。同一mid距離窓でUSDC建ての買い/売り厚み、(買い厚み−売り厚み)/(合計厚み)、spread×10000を計算する。SUI数量ごとに板を消費したVWAPとmidの差をbpsで示す（スプレッドを含み、手数料・gasは含まない）。数量を満たさない側はnull。10秒超、未来、欠損、非有限、非正、逆転、重複価格を拒否する。

RuleBasedStrategyは従来と同じaction/ruleを返す。scoreEvidenceに指標一致率、出来高品質、方向別板支持、スプレッド品質と入力板を保存する。重みは0.5/0.2/0.2/0.1、板なしでは前2要素を0.7で正規化。WAITはゼロ。校正されていない説明用スコアであり勝率ではない。UIも「未校正・勝率ではありません」と明記し100点形式にする。スコアで注文を許可しない。

BookAwareStrategyはオフライン比較でのみ明示的に選択する。既存workerのstrategy登録は変更しない。通常シグナルに板の方向支持0.1以上、設定内のspreadと数量別slippageを要求し、欠損はWAIT。既存の損切り・利確判断は保護目的として維持し、実際の注文には従来の市場検証・利益保護・リスク・停止ゲートが必要。

分析した周期の生板は新設book_observationsテーブルへobservedAtとhealthyを付けて保存する。判断根拠は既存strategy_decisionsへ保存。スキーマ追加はCREATE TABLE IF NOT EXISTSで既存DBを維持する。周期開始前に失敗した取得は既存cycle_audits/API診断で追跡する。サンプリングのない間隔を補間しない。板履歴の保存容量・保持期間は将来運用で管理が必要。

## 比較結果と限界

`node --import tsx scripts/compare-book-sample.ts`で再現。実測市場データではなくseed固定の合成600本、ウォームアップ200本、検証400周期。履歴板は存在しないため捏造せず空配列を渡す。

| 指標                     |      旧戦略 | 板フィルタ戦略 |
| ------------------------ | ----------: | -------------: |
| BUY / SELLシグナル       |       2 / 0 |          0 / 0 |
| 約定数                   |           0 |              0 |
| 勝率 / 平均SELL損益      |    算出不能 |       算出不能 |
| 最大ドローダウン         |           0 |              0 |
| モデル費用控除後損益USDC |           0 |              0 |
| 追加の見送り             | 利益保護2件 |      板欠測2件 |
| 板履歴カバー率           |      対象外 |          0/400 |

詳細: book-comparison-synthetic.json。取引ゼロの損益・DDは収益性の証明ではない。勝率はSELLゼロならnull。compareStrategiesは同一ローソク・同一費用・同一リスク設定で独立ポートフォリオを比較する。既存の次足openモデルを再利用し、分析には確定足までのみ渡す。板はobservedAtが判断時刻以下の最新観測だけ採用し、最新が異常なら古い正常板へ戻さない。未来の観測で過去を補完しない。過去10秒以内の板がなければ比較対象新規シグナルを止める。

手数料・gas・slippageは既存のモデルに含むが、歴史的に約定可能だった価格ではない。通信異常の安全性は既存タイムアウト・停止・復旧・重複抑止のモック/ループバック試験で検証し、このバックテストから実通信の成功は主張しない。

## PAPER結果による校正計画

今回利用可能な比較はSELLゼロで校正不能。過去の固定0.7の結果だけから新しいスコア全域の勝率を推定できない。今後はdecisionの時刻/scoreEvidence/strategy版とorderId、部分SELLの割当原価・純損益を結合する。見送ったシグナルを約定と混ぜない。複数部分SELLを独立した機会と誤認しないようポジション単位で集約する。

時系列で学習→検証→最終保留期間に分割し、各スコア帯の件数、実現純利益が正の割合、信頼区間、Brier scoreとreliability curveを算出する。最低件数と採用基準は結果を見る前に固定し、不足帯は確率表示不可。校正器は過去区間のみでfitし、次の区間へ適用する。板・通信欠測の頻度と約定選択バイアスも併記し、利益改善と校正品質を分けて評価する。

Windowsは明示したNode 24.22.1で検証。Dockerは既存digest固定のNode 24.22.1定義を維持。LIVE、秘密鍵、実資金検証は追加しない。
