# かんたん設定 1.0

基準: origin/main 5636b18（2026-10-20 に fetch で確認）。

## 変更内容

- SettingsPage に画面を分離し、運用スタイル、最大取引額、日次購入上限、利益保護の状態、独立したPAPER開始・停止を表示。
- 詳細設定は初期状態で閉じる。既存スキーマの全項目を日本語の説明付きで編集できる。戦略名およびEMA/MACD期間は従来の固定仕様を維持。
- 安全重視は最大注文2 USDC・日次10 USDC・最大スリッページ0.3%以下・利益保護有効・最低純利益0.05 USDC・最低利益率1.5%（内部値0.015）。既に厳しいスリッページは維持する。
- プリセットは保存済み設定全体のコピーから6項目だけ変更。損切り、日次損失上限、最大保有比率、その他の設定を保持する。
- 選択、変更内容の確認、明示的な「安全重視を適用」を分離。設定保存も確認後に行う。保存中は入力と保存を無効化し、同期ロックでも二重送信を防ぐ。
- 保存前のスキーマ検証、既存APIの検証、保存後の /api/state 再取得と全項目一致確認を行う。保存または再取得の失敗を成功表示しない。
- Profit Guard の判定・RiskEngine・PAPER制約・API・DBスキーマ・既存初期値に変更なし。緊急停止は常時独立して操作できる。

## 初期選択に関する扱い

設定がないUI上の提案は安全重視。ただし現行DBは生成時に既存初期値（5 USDC / 20 USDC / 1%）を保存する。保存済み値がプリセットと異なる場合は、新規DBでもカスタムと表示する。自動適用しないルールと保存済み値の不一致表示を優先した判断。初期値の移行・設定削除は行わない。
