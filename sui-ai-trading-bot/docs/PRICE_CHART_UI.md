# SUI/USDCチャートの期間・日時・操作

## 調査した既存構成

- `apps/dashboard/src/main.tsx` 内のSVG描画。チャートライブラリは使用していません。
- `BotEngine.snapshot()` の `candles` / `candlesByTimeframe` を既存の認証済み `/api/state` から取得。画面は既存の10秒周期で更新します。
- `BotDatabase.candles()` は時間足ごとに直近の取得元の最大1,000本を昇順で返します。DeepBook・GeckoTerminalの既存OHLCV取得上限も1,000本です。
- DeepBookの時刻はProviderでUnix秒の足開始時刻に正規化されます。確定足の終了は `(timestamp + timeframe) * 1000` です。Providerは通常、確定足のみを渡します。
- 既存チャートには5分・15分・1時間の時間足選択があり、表示期間選択はありませんでした。価格表示は直近100本でした。
- 既存EMAは全入力終値から共有の `ema()` を呼び、20本・50本の単純平均を初期値として計算していました。新しい価格チャートも同じ関数・同じ全履歴を使い、表示範囲だけ切り出します。

## 表示と操作

- 初期表示6時間。1時間・6時間・24時間・7日を取得済みデータだけで切り替えます。既存の時間足選択も維持します。
- 上部の開始・終了は、実際に描画する最初の足の開始と、最後の足の終了です。取得時刻や現在時刻で代用しません。足の詳細には開始・終了を別々に表示します。
- 日時と横軸は `Asia/Tokyo`。日付をまたぐ横軸には日付を付け、画面幅に応じて目盛りを減らします。
- ホバー、クリック、タップ、選択スライダーでOHLC・出来高・確定状態・取得元を確認できます。出来高などの記録がない場合は未取得と表示します。
- provenanceがある場合のみ再構築種別・取得時刻・根拠を表示します。◇は再構築、○は未確定です。provenanceがなければ「再構築情報なし」とし、元データとも再構築とも断定しません。
- 拡大・縮小、過去・新しい方への移動、横ドラッグ、最新データへ戻る操作に対応します。ホイール操作はCtrl併用でページの通常スクロールと区別します。
- キーボードではグラフにフォーカスして左右キー、＋／−、Homeを使用できます。選択スライダーでも各足を確認できます。
- 最新追従中は既存画面更新で新しい足を表示します。過去へ移動した場合はその時刻を維持し、最新へ戻る操作で追従に復帰します。
- 未取得・表示できないデータは「期間を取得できません」。追加取得は行わず、既存の画面更新を待ちます。

## 実際の表示可能期間

表示可能期間は受信した履歴次第です。連続した1,000本の場合、5分足は約83時間20分（約3.47日）、15分足は約10.4日、1時間足は約41.7日です。7日分の保証はありません。足が少ないときは取得済みの最大範囲を案内し、データのない時間帯は補完しません。SQLの上限・保持方法・API取得範囲は変更していません。

選択する「期間」と各足の「時間足」は別の設定です。過去の特定時点を表示する場合も、その時点以前を含む受信済み全履歴から計算したEMAを切り出します。未受信の過去データを補ってEMAを生成することはありません。

## 変更しない機能・残る制約

Provider、GeckoTerminalフォールバック、再構築、安全監視、AI判断、RiskEngine、Profit Guard、PAPER取引、24時間検証、LIVE拒否、DB、API制限、レポートを変更していません。チャート操作からAPIを呼び出す経路は追加していません。新しい依存ライブラリもありません。稼働中のDockerコンテナ・検証セッションは更新・停止・初期化していません。

表示専用の履歴取得APIや7日分の5分足取得は今回追加していません。RSI / MACDの既存チャートは直近100本のままで、今回の期間・操作機能は価格チャートに適用します。スマートフォンのピンチ操作には対応せず、タップ・スライダー・操作ボタンを使用します。実機の読み上げソフト・実機のタッチ端末での確認は未実施です。
