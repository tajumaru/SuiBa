# SUI アンロック前後で買い合図の成績は変わるか — 測定結果

## 結論（1行）
前窓・後窓とも「材料なし」。アンロック前後の合図は、窓の外の合図と比べて物差しを超える違いはなく、正味平均も全部マイナスだった。

## 判定（事前に固定した物差しで）
- 物差し：外との差が 0.3 ポイント以上 かつ 正味平均が +0.6%（往復コストの物差し）を超えたら「材料あり」。エピソード数 n が 30 未満なら「データ不足」。
- 前窓（アンロック前 72時間）：n=108 で判定可能 → **材料なし**（外より悪く、正味もマイナス）。
- 後窓（アンロック後 168時間）：n=277 で判定可能 → **材料なし**（差は最大 +0.22 ポイントで 0.3 未満、正味もマイナス）。

## 観察（正式な判定の外）
- 前窓は全ホライズンで外より悪く、特に +24h は −0.59 ポイント差。ただし事前に決めた物差しは「良くなる材料」の判定だけで、悪化側の物差しは決めていないため、正式判定は「材料なし」のまま。気になる傾向として記録に留める。
- 後窓は +4h だけ外より +0.22 ポイント良いが、0.3 ポイントの物差し未満で、正味も −0.37% とマイナス。買い材料にはならない。

## 前提と方法
- アンカー：毎月1日 00:00 UTC。対象は 2026-05-01、06-01、07-01、08-01、09-01、10-01、11-01 の 7 回（目標期間は 6 回分とされていたが、取得開始を 2026-04-24 にしたことで 5/1 の前窓まで全て収まり、7 回全部の窓が欠けなく測れた。12/1 のアンカーはデータ期間外）。
- 窓：前窓＝アンカーの72時間前〜アンカー、後窓＝アンカー〜168時間後。月次アンカーでは窓同士は重ならず、重なり除外に該当した合図は 0 件。
- データ：SUI_USDC 5分足、DeepBook インデクサー、2026-04-24T00:00Z〜2026-11-24T08:55Z、生 61,231 本。欠けスロット 509 本（0.8%）は直前終値の横ばい足（出来高0）で補完した（過去のバックテストと同じ扱い）。
- 合図の再現：本番コード（packages/strategy-engine の RuleBasedStrategy.analyze ＋ packages/indicators の calculateSeries、現在の main のもの）を時間順に実行。設定は本番値（oversold 45、emaGapShrink 有効・3本、出来高ゲート maxVolumeChange=4 はスキーマ既定、その他もスキーマ既定）。entryPrice は null、ProfitGuard の入口再現はなし。
- 成績：合図のローソク足の終値から +1h（12本先）/+4h（48本先）/+24h（288本先）の終値までの変化率。期間末尾で先の足が無い合図はそのホライズンだけ除外（+24h の窓の外が 905 件なのはこのため）。
